# Icon map

Each semantic icon (`AppIconName`) maps to exactly one glyph from exactly one source. Phosphor is the primary source. Tabler is used only when Phosphor has no suitable glyph, and every Tabler use carries a one-line reason.

Glyph identifiers are resolved by searching the installed package source, never guessed. The table is filled in batch P1B.
